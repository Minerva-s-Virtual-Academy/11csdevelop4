Networking: Exam Practice & Consolidation

Week B: Develop Task (Est. Time: 15 mins)

Lesson Companion: Quick Memory Scaffolds

Use these core concepts to scaffold your answers for the exam questions below.

  • TCP/IP Model Layers: Application (HTTP, FTP, SMTP), Transport (TCP, UDP), Network/Internet (IP), Data Link/Hardware (Ethernet, MAC).
  • Star Topology: All nodes connect to a central device (switch). If one cable fails, only that device disconnects.
  • Penetration Testing: Authorised simulated cyberattacks to identify and fix vulnerabilities.
  • Protocols: SMTP sends email; IMAP/POP3 receives email; HTTPS securely fetches web pages.

Question 2: Network Topologies (3 Marks)

A school plans to install a network connecting 20 classroom computers to a central switch.

Question: Explain one advantage and one disadvantage of using a star topology for this school network instead of a bus topology. (3 marks)

Memory Helper: Draw a mental picture. In a star, every node has its own cable to the switch. What happens if one cable snaps? What happens if you need to buy 20 separate long cables?

Official Mark Scheme & Self-Check

Advantage (2 Marks Max):

  • If one cable/device fails, the rest of the network continues to function (1 mark)
  • Because each device has its own dedicated connection to the central switch (1 mark)
  • Alternative: Easy to add new devices (1) without bringing down the network (1).

Disadvantage (1 Mark Max):

  • High installation cost / requires more cabling (1 mark)
  • If the central switch fails, the whole network goes down (1 mark)

Question 3: Network Security (3 Marks)

A business hires a security firm to conduct penetration testing on its internal network.

Question: Describe how penetration testing helps protect the organisation's software and network systems. (3 marks)

Memory Helper: Use the sequence: Authorised Attack → Find Weakness → Fix Vulnerability.

Official Mark Scheme & Self-Check

Award up to 3 marks for a linked description:

  • An authorised / simulated cyberattack is carried out on the network (1 mark)
  • To identify system security vulnerabilities / technical weaknesses (1 mark)
  • So that the security flaws can be patched / fixed before malicious hackers exploit them (1 mark)
